Assorted thoughts on IDE features, that must've been available for 10 years now

CRDT-based document history

Because Git sucks. Will allow late commits (commiting the past) and live collaborative editing of the code. No edit will be lost. A major topic that is a food for thought by itself.

Painting over document

Just give the user brush, colors and eraser. Anchor drawings to the nearest line of code. Version control them. Will significantly assist in developing and debugging algorithms.

Graphical debugging and oscillocsopes

  • Indispensable in audio DSP work.
  • An IDE may work like a Unity/Godot editor and provide own framebuffer to application for ease of prototyping.
  • For Visual Studio.
  • Oscilloscopes are external libraries that communicate with an IDE to provide inline oscilloscope of recorded in the current debug session values. An oscilloscope may be a function taking any value. An IDE may provide a way to filter and display a graph with value of the specific field in given structs.

Code bubbles

  • To make more efficient use of screen space.
  • Original Code Bubbles editor
  • Haystack editor — code bubbles for VSCode (ded((( )

Programmable search and replace

  • Commands of vi/vim.
  • Structural regexps of sam/acme.
  • Syntax-aware rewrite by example.

Elastic tabstops

  • To unify text and tables so all text-based features can be used on table data.
  • Original proposing blog article.
  • Again, Visual Studio exclusive extension.

Trivial extensibility

A plugin in its simplest form must be a file in the specified directory of other plugins like it. An IDE must know and suggest its API to the plugin developer.
